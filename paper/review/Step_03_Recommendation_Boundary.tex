\subsection{Separating Evidence from Assessment Judgments}
The revised reference workflow returns evidence quotations without an automatic assessment recommendation. A quotation can establish that text occurs in a bound source, but it does not establish technical correctness, student mastery or satisfaction of a rubric. The current keyword score remains a workflow-test fixture. Consequently, the provider contract requests observations only; legacy practice/continue fields are withheld rather than treated as student judgments. Candidate and reviewer read paths also omit recommendations from older stored results. Authorized review approves quotation release and does not establish the validity of a recommendation.

Regression verification covers opposite legacy recommendations, quotation-only responses, historical-result reads and reviewer approval. These checks establish the output boundary for authored cases. They do not establish semantic grading accuracy or demographic fairness, which remain separate evaluation requirements.
